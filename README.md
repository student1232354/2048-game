# 2048 Game

A responsive, browser-based implementation of the classic 2048 puzzle game built with modern JavaScript.

[**Live Demo**](https://student1232354.github.io/2048-game/)

---

## Features

- **Core Gameplay**: 4x4 grid movement, tile merging, random tile generation (`2` or `4`), score & high-score tracking.
- **State Management**: win (2048 tile reached), and lose states (no valid moves left).
- **Responsive Layout**: Designed for mobile (320px+), tablet (640px), and desktop (1280px).

---

## Tech Stack & Tools

- **Frontend**: HTML5, SCSS, JavaScript (ES6 Modules)
- **Environment & Bundling**: Node.js, NPM, Parcel
- **Deployment**: GitHub Pages

---

## Getting Started

### Prerequisites
- Modern Web Browser (Chrome, Firefox, Safari, Edge)
- Node.js & NPM installed

### Installation & Run

0. Make sure you have Node.js installed.

1. Clone the repository:
   git clone https://github.com/student1232354/2048-game.git

2. Navigate to the src directory:
   cd 2048-game/src

3. Start the local server:
   node server.js


---

## How to Play

- Click **Start** / **Restart** to begin a new game.
- Use **Arrow Keys** to move tiles:
  - `ArrowUp` — Move Up
  - `ArrowDown` — Move Down
  - `ArrowLeft` — Move Left
  - `ArrowRight` — Move Right
- Merge tiles with matching values to reach **2048**!
